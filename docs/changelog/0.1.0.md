# dn v0.1.0

Date: 2026-11-16

首个版本, 提供多连接分片下载与断点续传.

## Features

- CLI: `dn <url>` 即可下载, 把文件按连接数均分后并发下载, 默认 8 个连接, `-n` 可调整到 1 到 64.
- CLI: 动态分片. 有连接空闲时, 把剩余最多的分片从中间切开交给它, 慢连接不会拖住整体进度.
- CLI: 断点续传. 中断后用同一条命令重新运行即可继续, 已完成部分不会重新下载; 服务器文件变化或不再支持 Range 时自动改为从头下载.
- CLI: 服务器不支持 Range 时自动退回单连接下载; 支持 302/307 等重定向, 分片请求直接发往最终地址.
- CLI: 服务器限流 (429/503) 时降低并发连接数并在之后逐步恢复; 连接长时间无数据自动重连; 单个分片反复失败时先跳过, 让其它分片继续.
- CLI: 目标文件已存在时改名为 `name (1).ext` 避免误覆盖, `--overwrite` 可显式覆盖.
- 配置: 支持 `~/.config/dn/config.toml`, 包含默认下载目录, 连接数, 最小分片大小, 代理和自定义请求头; `dn config init/show/path` 管理配置.
- 交互: 终端下显示实时进度条 (大小, 速度, 剩余时间, 活动连接数), 非终端环境改为定时输出进度日志.
